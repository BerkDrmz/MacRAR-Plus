# MacRAR Plus 2.3.2

2.3.1'in arayüzü, arşiv araçları ve optimizasyonları korunur. Arşiv haritası ekranı küçük SwiftUI görünüm parçalarına ayrıldı; uzun metin ifadeleri ayrı hesaplanır. GitHub'ın macOS 14 ortamındaki eski Swift derleyicisinin tür denetimi sırasında durması giderildi.

Apple Silicon/macOS 13+, build 13. ZIP/DMG paketleri [GitHub Releases](https://github.com/BerkDrmz/MacRAR-Plus/releases/tag/v2.3.2) üzerinden indirilir. Paket ad-hoc imzalıdır; Developer ID imzası veya notarizasyon içermez. MIT kaynak telif bildirimi ve motor lisansları korunur.
